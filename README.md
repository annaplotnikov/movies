Репозиторий Movie Catalog (Posters)
Описание
Movie Catalog – это набор консольных утилит на 8 языках программирования для управления коллекцией фильмов с поддержкой постеров. Программа позволяет:

Добавлять фильмы с указанием названия, года выпуска, рейтинга, описания и пути к постеру (изображению).

Удалять фильмы по ID.

Просматривать список всех фильмов с краткой информацией (ID, название, год, рейтинг, путь к постеру).

Искать фильмы по названию.

Показывать детальную информацию о фильме (включая описание).

Открывать постер во внешнем просмотрщике (системная команда open/xdg-open/start).

Данные хранятся в локальном JSON-файле (movies.json). Программа работает в интерактивном и пакетном режимах (через аргументы командной строки).

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения. Внешние зависимости не требуются (используются только стандартные библиотеки).

Язык	Команда запуска
Python	python movies.py [команда] [аргументы]
JavaScript	node movies.js [команда] [аргументы]
TypeScript	ts-node movies.ts [команда] [аргументы]
Go	go run movies.go [команда] [аргументы]
Java	javac MovieCatalog.java && java MovieCatalog [команда] [аргументы]
C#	csc MovieCatalog.cs && MovieCatalog.exe [команда] [аргументы]
PHP	php movies.php [команда] [аргументы]
Ruby	ruby movies.rb [команда] [аргументы]
Использование
text
movies <команда> [опции]
Команды
Команда	Описание
add	Добавить фильм. Требует --title, --year, --rating, --poster.
remove	Удалить фильм по --id.
list	Показать список всех фильмов.
search	Поиск фильмов по --query (в названии).
info	Показать детальную информацию о фильме по --id.
open	Открыть постер фильма по --id во внешнем просмотрщике.
help	Показать справку.
Опции
Опция	Описание
--title	Название фильма.
--year	Год выпуска (число).
--rating	Рейтинг (число с плавающей точкой).
--poster	Путь к файлу постера (изображение).
--description	Описание фильма (опционально).
--id	ID фильма (число).
--query	Поисковый запрос (строка).
--data	Файл данных (по умолчанию movies.json).
Примеры
bash
# Добавить фильм
python movies.py add --title "Inception" --year 2010 --rating 8.8 --poster "posters/inception.jpg" --description "A thief who steals corporate secrets..."

# Список всех фильмов
python movies.py list

# Найти фильм по названию
python movies.py search --query "Inception"

# Показать детали фильма с ID 1
python movies.py info --id 1

# Открыть постер
python movies.py open --id 1

# Удалить фильм
python movies.py remove --id 1
Формат хранения
Данные хранятся в JSON-файле со следующей структурой:

json
{
  "movies": [
    {
      "id": 1,
      "title": "Inception",
      "year": 2010,
      "rating": 8.8,
      "poster": "posters/inception.jpg",
      "description": "A thief who steals corporate secrets..."
    }
  ],
  "next_id": 2
}
Особенности реализаций
Все версии используют только стандартные библиотеки языка.

Цветной вывод (ANSI) для улучшения читаемости (опционально, в некоторых реализациях).

Данные сохраняются в JSON.

Поддержка интерактивного режима (если команда не указана, программа запрашивает ввод).

Обработка ошибок (неверный ID, отсутствие файла).
